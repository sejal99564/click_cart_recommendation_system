# Research results

The original paper results and reproduction requirements are documented in [research alignment](../research/RESEARCH_ALIGNMENT.md). The latest synthetic report is [experiment-results.json](../frontend/public/experiment-results.json). Run `python -m ml.run_experiments --seed 42` to reproduce the default settings. Each run preserves its report in `frontend/public/experiment-runs` and its model artifacts in `models/artifacts/<run-id>`.
